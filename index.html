π Pi Testnet Token Studio

أنشئ توكن تجريبيًا بسهولة

الموقع يعمل مباشرة دون تسجيل دخول Pi أو كلمة مرور إدارة. أدخل العناوين العامة وبيانات التوكن، بينما تبقى المفاتيح السرية داخل Vercel فقط.

بيانات التوكن

تنبيه أمني: لا تُدخل المفاتيح السرية في الصفحة. ضع مفاتيح محافظ Testnet فقط داخل Vercel باسم ISSUER_SECRET وDISTRIBUTOR_SECRET. العناوين العامة فقط تُكتب هنا.

ماذا يحدث؟

Trustline

محفظة Distributor تثق في الأصل، وهنا يُعرّف الأصل على السلسلة.

Home Domain

ربط حساب Issuer بدومين موقعك الذي يستضيف ملف /.well-known/pi.toml.

Mint

يرسل Issuer الكمية المحددة إلى Distributor، وهي عملية الإصدار.

Wallet / DEX

انتظر فحص Pi Server، ثم أنشئ Liquidity Pool من Pi Wallet حتى يمكن المبادلة.

قبل التشغيل

  • محفظتان مفعّلتان على Testnet
  • رصيد Test-Pi للرسوم
  • دومين HTTPS منشور
  • لوجو عام قابل للتحميل
  • Vercel Blob متصل بالمشروع
  • المفاتيح السرية في Vercel
